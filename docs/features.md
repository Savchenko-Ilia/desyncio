# Features — Module 2: DES primitives

Built on module 1. Concepts follow SimPy (AGENTS.md §1); the API is asyncio-style (D019); interrupts are a
dedicated exception (D020). **Reuse asyncio first (principle 6, D022):** every row says what is delegated to
asyncio. Own waiting/queueing logic only where asyncio has none, built on `asyncio.Condition`/futures.
Common rules for every feature in this module:
- **Virtual time:** all blocking happens in virtual time.
- **Cancellation:** a waiter cancelled or interrupted while queued is removed and leaves no stale reservation. Where we delegate, this comes from asyncio and is tested, not re-implemented.
- **Determinism:** ordering is deterministic (FIFO or `(priority, request order)`), with a same-seed determinism test.
- **Validation:** bad arguments raise `TypeError`/`ValueError` with clear messages.
- **Imports:** each feature is importable from its own module. Top-level exports come only from API-01.
